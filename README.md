# Parallax

A fixture-only GUI laboratory built with Go, React, Tailwind 4, Hollis Labs design-kit and Chimera. No database, credentials, providers or external services are required at runtime.

```sh
make run
# http://127.0.0.1:18441
```

Requires Go 1.26.6+ and Node 22.12+. Dependency installation needs network access; the built binary runs independently. `make ui-dev` starts Vite with same-origin fixture/plugin proxy to the running Go host. `make fixtures` explicitly regenerates bundled JSON; `make check` validates Go, frontend and CSS contracts.

Activity, Mission Control and Usage share deterministic Go-generated 8-record and 80-record profiles, seed 4421/reference time `2026-10-04T14:30:00Z`. Named scenario controls show populated/empty/loading/error/degraded/unavailable/permission-denied/long-label/large/sparse/unknown-status examples. Fixture timeline review provides bounded local play/pause/step/seek/reset over authored UTC evidence boundaries. Operations, run details, Layouts, plugin counters and compatible Observability projections use the same cutoff; future states/messages/outputs/usage and uncovered bins remain unavailable. Loading/error/degraded/unavailable resource overrides are presentation-only. Scenario/reset/seek/source retirement cancels old timer and presentation producers. Other families are explicitly full-snapshot views.

Run detail joins actual sessions/messages/tool calls/logs/traces/spans/events/usage fixtures. Selection survives ordinary view navigation and playback while its record is admitted; seek before admission, reset or scenario change clears it. Send/Save/Stop controls terminate at a transient intent inspector; fixture business records are unchanged. Account/authentication, microphone, model, tool, provider and remote business workflows are absent.

One viewport AppShell owns layout. Ordinary routes use `.page-scroll`; Layouts replaces it with the actual ListPageLayout/DetailPageLayout primary scrolling body. Desktop split details own an explicit bounded aside scroll; OverlaySidebar owns temporary modal navigation/detail scrolling and focus behavior. DetailDialog supplies other inspection modal focus behavior. Review identifiers are shareable through URL parameters `view`, `scenario`, `theme`, `mode`, `viewport`, `layout`, `navigation`; selections/drafts are transient and excluded. Review controls choose palette, light/dark mode and constrained viewport. CSS source registration imports the published design-components/dashboard/chat source.css entries (dashboard theme also imports these). UI uses root theme attributes; simultaneous subtree themes are not assumed.

A real `ops/g1` plugin contributes summary/modal widgets, a detail panel, declarative presentation actions and a reviewed simulation handler through Chimera registry v2 delivery, digest-verified plugin-registry loading and shared plugin-host-ui rendering. The Vite provisioning plugin supplies one shared React importmap runtime. The shared action gateway admits local navigation/modal presentation and transient simulation receipts; scenario/filter context changes fence pending actions. Main-origin execution is an explicit host choice restricted to the repository's reviewed fixture bytes; this is not a third-party installation UI or sandboxed-frame implementation.

`third_party/README.md` identifies the unpublished host-ui packed candidate and digest. Other frontend dependency versions are exact in package.json/lockfile. `.folio.yaml` retains scaffold provenance; scaffold wiring was adapted for root mounting and Chimera.

`make storybook` opens controlled operations, communications and chat compositions plus a primitive baseline; `npm run build-storybook --prefix frontend` builds it. Export coverage is an inventory, not an assertion that every component is exercised. See [review evidence and gaps](docs/review.md).

Browser review: install Chromium once with `npm exec --prefix frontend -- playwright install chromium`, then `make browser`. Linux runners also need Chromium's shared libraries; CI installs them via Playwright. Playwright starts fresh built app/Storybook hosts itself. [Actionable export coverage](docs/coverage.md) tracks1,308 declaration names across13 runtime/base/kit packages, classified as507 visual components,621 types and180 nonvisual/value exports. Explicit reviewed/partial/deferred/unsupported dispositions separate representative behavior evidence from170 exact public-entry imports. CI validates inventory freshness and page/story/check pointers after Storybook; standalone Storybook contains109 stories. Complete behavioral implementation is not implied by inventory tracking.

Contacts, Messages and Chat share the versioned `communications/v1` artifact, joined to operations sessions/runs/tools. Directory selection opens the related email, SMS or Tether-style conversation. Draft send and card responses open only a transient intent inspector. Scripted streaming advances manually and clears on session/scenario change; historical tool results are read-only. The released chat kit supplies cards, history, composer, tools, reasoning, plans, queue, attachments, sources and artifacts. Contacts/Messages are app-owned compositions: dedicated kit packages are not published. The complete chat package license, including Apache-2.0 upstream attribution, is preserved in [kit-chat-LICENSE.txt](frontend/public/kit-chat-LICENSE.txt).

Administration embeds released AdminContent0.1.0, settings0.2.0 and observe0.1.1 inside the existing shell. Settings shows desired values/provenance/locks/pending application; Status and Diagnostics show separate fixed-clock observations. Explicit-held setup/save/apply outcomes are scripted inspections, never saved state or restarts. Account uses a reviewed private0.0.0 candidate for profile/preferences/identity and metadata-only access views, plus app-owned related user/role/permission directories. Unknown/error identity gates withhold profile/access actions. Candidate provenance and full MIT license are preserved in third_party and public assets.

Observability adds searchable logs, linked traces/spans/tools/usage and released observation-kit health/stats/exact-series/diagnostic views. Manual timeline review reveals only authored records through a UTC cutoff; the full-snapshot run inspector is labeled separately. Per-resource receipt timestamps survive scripted refresh failures. Zero, null gaps, missing/stale/denied evidence and bounded diagnostic failures are distinct. Cost stays an app-owned authored USD estimate, with provider attribution unavailable. No telemetry collection or refresh fetch occurs.

Developer review adds bounded authored source/proposal/commit/stack/test/output records and a read-only workflow canvas tied to the operations graph. Source drafts and graph selection/viewport are transient; terminal text cannot execute and save/run controls only inspect refusals. Code and workflow use explicitly unpublished, licensed candidates documented under `third_party`; optional ANSI and React Flow load only in their separate review tabs. Highlighting remains unadopted.

Voice review uses original generated tone WAVs and authored timed text joined to the chat/operations fixtures. Recording and transcription are selectable appearances with capture disabled; actual local AudioPlayer playback/seek starts only through user controls. No microphone/device enumeration, upload, speech provider or saved transcript exists. The private kit-voice candidate and media algorithms/licenses/checksums are documented in provenance and review notes; its media-chrome player loads only when the Audio tab is selected.

Layouts compares the same linked operations records as list, sortable keyboard table, split detail and focus-managed drawer. Rail/header/drawer navigation uses existing AppShell slots; bounded detail width and layout choices are local presentation controls. Changing composition preserves selected records; scenario changes retire them. Portable stories reuse the same models/components without APIs.

Observability distinguishes retrospective recorded projections from resource receipt snapshots. Future health/diagnostic receipts are withheld; out-of-window or incompatible80-record sources are unavailable. Full-snapshot communications/admin/developer/voice are not reconstructed as operation timeline events.
