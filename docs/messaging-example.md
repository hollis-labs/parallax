# Messaging Example

`/?example=messaging` and the Workbench destination open a standalone one-shell messaging review. The shared fullscreen `App Examples/Messaging` stories mount the same composition without an API or transport.

The contact directory, email/SMS/Tether inbox, conversation detail and declared attachments use the unchanged `communications/v1` snapshot (`parallax/v3`, seed 4421, original UTC reference 2026-10-04T14:30:00Z). Its three contacts, three conversations, six messages and three attachments retain their original relationships. Latest-message ordering uses the supplied message timestamps; the fixture does not claim a conversation-updated timestamp. This independent snapshot never inherits the operations playback cutoff. The optional related Chat link resolves the exact current contact and run relationship.

Known empty and zero matches are distinct from inaccessible counts, which remain Unknown. Loading, error, denied and unknown appearances withhold records; degraded retains the labelled original snapshot. Locked permits read-only attachment inspection and refuses composer changes/submission. Long text and failed/unknown delivery are explicitly authored presentation appearances; they do not alter supplied message bodies, timestamps or delivery status.

Contacts, channel, search, conversation, appearance and palette are finite URL state with reload/back support. Search typing retains its control and caret. Selection must remain admitted by the current contact, channel, query and resource. The application owns one viewport: directory and inbox-list scrolling are bounded, while a selected conversation has a bounded keyboard transcript and pinned local composer. Narrow views use native navigation/review sheets and a conversation-back action.

Attachment admission requires the current conversation/contact, actual run relationship and the current message's `attachmentIds`. A global attachment ID is insufficient. Draft Enter and the visible inspection button inspect only the trimmed current local value. Shift+Enter and native IME composition do not submit. A finite held outcome reports only local inspection; messages and delivery records never change. Source, selection, query, channel, draft, reset, sheet transitions and unmount retire old callbacks and outcomes. React.StrictMode creates a fresh layout-effect-owned presentation session; focus restoration is current, connected and canceled by newer transitions.
