## Fixed evidence and authored appearances

`conversation-review/v1` joins immutable communications/v1 CHAT/session/card IDs to the actual operations/v2 messages through sessionId and runId at fixed UTC2026-10-04T14:30:00Z. Every supplied message retains its ID, role, content and timestamp. One finite older row may be revealed from the existing two-message session; nothing is fetched, appended or persisted. Composer Arrow-up history is supplied from the recorded user message only. Session/source replacement changes the presentation lease, not the records.

The original communications card records have no prior response field. The separately labelled prior selector authors appearances and never pretends those outcomes were recorded. Actual pinned classification is:

The host consumes actual classifyPriorResponse/acceptsInput; it does not infer from the English names. Confirmation hides its action footer for non-open classifications; Prompt keeps nonterminal locked controls disabled and terminal output read-only. Submitted prompt answer and prior action labels are explicitly authored appearances, not asserted fixture receipts. Locked host policy withholds response cards and disables the composer without fabricating a prior state. Denied policy unmounts transcript, composer and card content.

Three labelled manual preview chunks are authored separately from source messages. Streaming/stalled status remains outside ChatStream items and is never counted as a committed message. Advance is finite, clears transient drafts/inspection, and never appends. At the third chunk the text remains uncommitted; Stop retires the preview status, after which a fresh draft can be inspected locally. No timer, model, transport or live response collection is implied.

## Callback and native contracts

ChatInput Enter inspects its trimmed current draft; Shift+Enter adds a newline. Actual native isComposing/keyCode229 prevents submission. Busy remains editable while Enter/Send is suppressed. Optional Stop only retires the authored local preview. Prop-driven Arrow-up/down history has no persistence. No suggestions, attachments, upload, markdown/streamdown, images, external URL, clipboard or storage callback is provided.

Confirmation/Prompt callbacks return void. Their internal async submitting state settles normally while the host separately holds a finite local candidate inspection; no invented busy prop or submitted-prior mutation is used. Confirmation candidates must match the current selected action ID/item ID exactly; prompt candidates must match the current question ID and trimmed current note. Additional/stale decisions, answers or notes are refused. Decline uses only the actual canceled outcome. Emitted status is a candidate intent, never applied to supplied card prior or transcript. The authored action vocabulary has no authorization/approval evaluator.

Every immediate callback and held producer rechecks source/session/card/prior/current draft/policy/render lease. Current prompt edits also require actual open classification. Effect setup owns a fresh finite session, so StrictMode setup/cleanup/replay admits fresh candidates; captured old sessions are disposed independently. Source/session/prior/card/state/mode/reset/unmount retire callbacks, held results, targets and focus; draft/manual-step/Stop/history changes retire local inspections. Held outcomes re-evaluate current candidate before ticket.commit. Close/focus callbacks require current lease/open/origin and cancel RAF on retirement/new admission.
