# Controlled primitive gallery

The Primitives route and `Primitives/Controlled gallery` stories share `frontend/src/primitives/Gallery.tsx` and its `primitive-gallery/v1` projection of the existing operations/v2 graph. It deliberately uses an unfiltered, fixed full snapshot: entry pauses operation playback, and retained operation filters do not restrict gallery choices. No new wire schema, upstream source copy, dependency candidate, save, authentication evaluator or external request is introduced. All nine components come from the existing exact `@hollis-labs/design-components@0.4.0` dependency. Local inspection uses the unchanged, provenance-recorded Chimera admin-session adapter.

| Component | Bounded reviewed behavior | Public API limits / remaining variations |
| --- | --- | --- |
| Pill | Five actual tone paints/dots, unknown domain label mapped visibly to neutral | Closed tone union; no invalid prop casting. Other appearance variants remain outside this review. |
| Callout | Normal/info/failure/denied/unknown policy messages, actual distinct paints and retained-draft scripted refusal | Host adds status/alert semantics; the component does not automatically announce all content. |
| ProgressBar | Real completion, known-empty zero, withheld values, lower/upper clamping, indeterminate animation and reduced-motion | Published `keyframes.css` is required. Host supplies named numeric progress semantics; indeterminate child supplies busy semantics, contextualized by its named section. |
| OverflowMenu | Keyboard opening, disabled inspection actions, menu-opened form, origin focus return | Gallery has no row-activation ancestor: row isolation is not claimed. Trigger has no disabled prop; host gates actual actions. |
| CollapsibleSection | Keyboard expand/collapse, selected identity/trace joins, keyed reset | It owns uncontrolled disclosure state; source/selection reset remounts it. Fixed-open variants are not claimed. |
| Combobox | Controlled record selection, search/no-match, clear, long labels, keyboard Escape and trigger return | No disabled prop. Loading/error/denied policy withholds it instead of inventing an API. |
| ConfirmDialog | Local archive-intent inspection, busy buttons, explicit Escape cancellation, held-result retirement and focus return | Busy does not disable Escape internally. Host cancels pending outcomes; no fixture is archived. |
| DetailSection | Actual task/run/session/trace detail and draft section, bounded/narrow content | A section primitive, not an independent data loader or permission evaluator. |
| FormDialog | Invalid/busy native-submit guard, keyboard submission, held note inspection, edit/close/reset retirement, refusal retains current draft, narrow body/footer scrolling | Disabled/submitting buttons do not prevent native form submit callbacks. Host checks synchronous lease/open/draft/selection/busy state before admitting any callback. No note is saved. |

Eight portable initial appearances are recorded, empty, loading, read failure, denied, locked, long content and unknown. Dialogs/menu are interacted with in these same shared artifacts; no blanket assertion covers every prop permutation. Empty has observed zero; loading/error/denied withhold record content and completion. Locked remains readable and prevents local mutation-intent controls. Unknown presentation status is labeled without changing recorded task state.

Selection, drafts, result text, disclosure and open overlays retire on state/reset/source replacement or navigation away. Editing a held draft invalidates its older producer. Producer release is explicitly FIFO: releasing an older retired producer cannot attach its outcome to a new draft/selection/source. Admission checks guard stale callbacks themselves, while tickets independently guard late commits. Focus restoration is scoped to the alive instance, current lease and original connected target, cancelled on new retirement/unmount; a retired close callback cannot retire a newer dialog.

The existing AppShell and ordinary `.page-scroll` own the viewport/page. Modal body scrolling is deliberate and bounded by the released FormDialog; the sticky footer and last body reset control remain reachable on narrow screens. Published CSS utility registration and tokens are reused; `keyframes.css` is directly imported, and a scoped reduced-motion rule disables indeterminate animation. No optional code/workflow/audio dependencies are introduced to core startup.

Evidence: `frontend/tests/primitives.spec.ts` checks real DOM paint, fill geometry, native guards, keyboard focus containment/return, reduced motion, narrow theme/width, source/draft retirement, same-frame close/new-open focus, filtered-playback entry, and portable remount with no API/plugin requests. `frontend/src/primitives/contracts.ts` checks actual public types and rejects unsupported tones/Combobox disabled props. Story IDs are `primitives-controlled-gallery--recorded`, `--empty`, `--loading`, `--read-failure`, `--denied`, `--locked`, `--long-content`, `--unknown`. Full regression checks retain prior playback, date/null and optional-loading contracts.
