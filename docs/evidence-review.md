# Controlled evidence payload inspection

The Evidence route and `Evidence/Controlled inspector` stories share `frontend/src/evidence/Inspector.tsx` and its app-owned read-only index of the existing operations/v2 task/run/trace/log/tool graph. No new fixture collection, event history, receipt or telemetry wire is invented. Source timestamps and joined IDs are retained. The route explicitly uses the unfiltered full snapshot, pauses operation playback, and does not imply reconstruction of this inspector at a historical cutoff.

Four components are adopted from the existing exact published MIT `@hollis-labs/design-components@0.4.0`: **JsonViewer, PayloadSummary, MetaList and SearchInput**. Installed public declarations and runtime were audited; no dependency version, candidate archive, source copy or upstream file changes. Existing DetailDialog and DetailSection supply the modal/section chrome. JsonModal unconditionally includes a CopyButton footer, and PayloadActions combines view with copy. Neither has a public action-disable/override contract. They and CopyButton remain deferred under this checkpoint's no-clipboard policy, not defective or replaced upstream. The app composition does not count as JsonModal adoption. Metric is outside this bounded slice.

| Export | Bounded evidence | Public contract limits |
| --- | --- | --- |
| JsonViewer | Actual pretty-printed object/nested/string/number/boolean/null syntax, token paint, long wrapped payload, readonly malformed-input text fallback | It pretty-prints values; it is not the exact source text, editor, schema validator or streaming viewer. Host supplies the separately labelled exact raw text. |
| PayloadSummary | Index metadata projection (first three entries), actual selected payload preview (first four top-level entries), nested serialization, false/scalar fallback and malformed raw fallback | The released helper truncates serialized nested values at48 characters; no promised schema validation. Metadata and payload previews are labelled distinctly. |
| MetaList | Real record kind/task/run/source/UTC metadata with actual definition-list semantics and narrow columns | One through four columns are supported; loading/denied/error host states withhold records instead of inventing data props. |
| SearchInput | Controlled150ms filter debounce, slash-to-focus, editable-target guard, Escape-clear/blur, source/selection/open/reset/unmount retirement | No loading/disabled prop. Host gates mounting and disables slash binding while its modal is open, preventing hidden-background focus. |

Initial appearances: recorded, nested, long, empty, loading, denied, read failure, unknown classification and malformed raw. Nested is an actual joined runDetail bundle. Long adds a bounded explicitly labelled **presentationAnnotation** alongside the unchanged record. Unknown adds an explicit presentation classification and `recognized:false`, leaving source record status unchanged. Malformed raw is an authored diagnostic string, labelled as text rather than parsed source evidence. Empty is a known zero index; unavailable/denied/error resources withhold record counts and payload. Source resource denial takes precedence over a selected empty appearance.

The index has12 rows per local page. Search checks existing identifiers and record content; query/kind changes clear selection and modal. Source identity includes dataset version/profile/scenario/reference clock; same-scenario replacement therefore clears old selection/search/overlay. The replacement story uses a labelled reviewed copy of the same authored records with distinct source identity, not new observations. Search timers are owned by the published component and cancelled through remount on selection/modal admission or source/state/reset; synchronous alive/lease guards additionally reject stale callbacks. Focus RAFs are cancelled on retirement/unmount and check the current lease/target/open state. No clipboard interception or CSS hiding of action controls is used.

One existing AppShell and ordinary `.page-scroll` own the viewport/page. DetailDialog has its deliberate bounded body scroll and sticky local Close/Reset footer. Host wrappers allow long summary scalars and JSON/raw text to wrap within narrow panels; underlying syntax/data behavior is unchanged. Theme tokens and existing CSS registration apply. Code/workflow/audio optional entries remain independent. No API acquisition, file download, clipboard, save, tool execution or provider call is introduced.

Evidence pointers: `frontend/tests/evidence.spec.ts`, `frontend/src/evidence/contracts.ts`, `frontend/src/evidence/model.ts`, `frontend/src/evidence/Inspector.tsx`, `frontend/src/evidence/Evidence.stories.tsx`. The focused checks cover deterministic graph/bounds/withholding, actual syntax and summary/definition metadata, keyboard debounce/modal scope, pending source/selection retirement, portable same-scenario replacement, narrow dark modal content and API/clipboard/download absence. Existing regressions remain required. Behavior dispositions are bounded; other public exports and prop permutations stay actionable in the inventory.
